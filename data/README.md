# BGOpt data contract

`raw/` contains unmodified collector JSONL. Each row may include an
`experiment_id` and `scenario`, but it must never contain invented foreground
latency, progress, or action outcomes.

`processed/` contains derived model features joined to human-supplied labels.
The labels file distinguishes `workload_label`, `process_role`, and
`resource_label`; none of them is an action.

Outcome CSVs use the columns generated by `bgopt outcome-template`. Fill them
only from measured experiment results. Keep raw telemetry, labels, controller
audit JSONL, and outcome files together under one experiment ID.
